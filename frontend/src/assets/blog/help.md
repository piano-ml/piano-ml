# Application Documentation

This is the application documentation.

If you need help and answers on how to learn piano, I would highly recommend this forum: [/r/pianolearning](https://www.reddit.com/r/pianolearning/)

## Workbench

![/assets/images/workbench.webp](/assets/images/workbench.webp)

- **L**: Start playing the score
- **K**: Toggle button - The app will wait for your right hand
- **J**: Toggle button - The app will wait for your left hand
- **I**: Toggle button - Display or hide the keyboard
- **C**: Go back to the score information page
- **B**: This shows the duration you played (pauses for wrong notes are not counted)
- **A**: Go back to score selection
- **H**: Toggle button - Activate loop mode; the playing will loop on the selected range (N)
- **N**: This is the slider for selecting the start of a part of the score. You can also select the end of the score. This way you can, for example, decide to work only from measures 4 to 6.
- **D**: Go back to the beginning of the selected measures, or if already at the beginning, reset the slider
- **M**: It is possible to set your keyboard size in user preferences. If you have a small keyboard, the app will not wait for keys you can't play

## Import score.

It is possible to import your scores. 

In case of .midi, .musicxml files the process takes only few seconds.

In case of .pdf files it can take from 5 to 10 minutes: Optical Music Recognition can be imperfect. If you like to make a correction, it's possible to download back the music xml file and edit it using the music XML editor such as [Musescore](https://musescore.org) (free and powerful)

## Midi Configuration

There is no special midi configuration needed. Midi connection shall work out of the box. If it is not working:
- did you reject midi authorization when prompted ? If so you must go in your browser setting to remove the blacklist.
- Is your keyboard plugged and on ? If no then just try to reload the webpage

It's also possible to inform the app about your keyboard size (ex 42, 66 or 88 notes) in the [user preference page](/account/home).
