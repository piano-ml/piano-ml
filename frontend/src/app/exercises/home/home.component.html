Scales Agility
Level 1 Cycle

Start with 2 keys per day. Each day work on a different key pair. The following sequence takes 12 days to complete a full cycle of all 24 major + minor keys.

    Major Keys (Sharp):
  • Day {{ 1 }}: {{ 'C' | noteName }} + {{ 'G' | noteName }}
  • Day {{ 2 }}: {{ 'D' | noteName }} + {{ 'A' | noteName }}
  • Day {{ 3 }}: {{ 'E' | noteName }} + {{ 'B' | noteName }}
    Major Keys (Flat):
  • Day {{ 4 }}: {{ 'F' | noteName }} + {{ 'Bb' | noteName }}
  • Day {{ 5 }}: {{ 'Eb' | noteName }} + {{ 'Ab' | noteName }}
  • Day {{ 6 }}: {{ 'Db' | noteName }} + {{ 'Gb' | noteName }}
    Minor Keys (Sharp):
  • Day {{ 7 }}: {{ 'A' | noteName }} + {{ 'E' | noteName }}
  • Day {{ 8 }}: {{ 'B' | noteName }} + {{ 'F#' | noteName }}
  • Day {{ 9 }}: {{ 'C#' | noteName }} + {{ 'G#' | noteName }}
    Minor Keys (Flat):
  • Day {{ 10 }}: {{ 'D' | noteName }} + {{ 'G' | noteName }}
  • Day {{ 11 }}: {{ 'C' | noteName }} + {{ 'F' | noteName }}
  • Day {{ 12 }}: {{ 'Bb' | noteName }} + {{ 'D#' | noteName }}

You can add the Chromatic Scale to any of these keys, starting on the key note.

Note that enharmonic keys like C# and Cb major are skipped. These are identical to Db and B, respectively.
